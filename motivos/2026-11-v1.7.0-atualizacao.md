# Atualização sugerida para o AnyBox 1.7.0

As versões anteriores continuam ativas. A atualização para a versão 1.7.0 é opcional e não impede o uso das versões antigas. Não há versão mínima obrigatória.

A versão 1.7.0 corrige o copiar e colar de arquivos entre o AnyDesk remoto e as caixas do Sandboxie, preservando o funcionamento das cópias seguintes.

## Como atualizar, se desejar

1. Encerre as instâncias antigas do AnyBox e do AnyDesk abertas por ele.
2. [Baixe o AnyBox 1.7.0](https://github.com/kleitofi/anybox-releases/releases/download/v1.7.0/AnyBox.exe).
3. Substitua o executável antigo e abra o novo AnyBox.

Texto, arquivos e pastas foram validados nos dois sentidos. Para copiar arquivos, o limite é de 200 MB por cópia; acima disso, use a transferência de arquivos do AnyDesk.

Se uma máquina guardou o bloqueio anterior no cache, conecte-a à internet e abra o AnyBox novamente para consultar a política atualizada. O cache do GitHub pode levar alguns minutos para propagar a alteração.
